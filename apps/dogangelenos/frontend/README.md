# Dog Angelenos - Frontend

Next.js frontend for the Dog Angelenos dog training website.

## Quick Start

```bash
cd apps/dogangelenos/frontend
npm install
npm run dev
```

Visit: http://localhost:3004

## Features

- Professional dog training website
- Online booking form
- Gmail authentication
- SEO optimized
- Mobile responsive
- LA-themed design

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion

## Development

```bash
npm run dev      # Start dev server
npm run build    # Build for production
npm start        # Start production server
npm run lint     # Run linter
```

## API Integration

The frontend connects to the backend API at `http://localhost:8000`

See `../backend/README.md` for backend setup.
